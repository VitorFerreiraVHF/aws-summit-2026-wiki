# AWS Summit 2026

Bem-vindo a wiki de conhecimento do AWS Summit 2026.

Esta base foi pensada para sair do modo "arquivo solto" e virar memoria compartilhada: cada foto, gravacao e anotacao deve apontar para algum aprendizado, decisao, referencia ou oportunidade pratica.

## Proposito comunitario

Este projeto e mantido sem fins lucrativos para documentar o AWS Summit 2026, melhorar a experiencia de consulta e compartilhar aprendizados com a comunidade AWS e pessoas interessadas em tecnologia. O repositorio nao representa a AWS nem substitui os materiais oficiais; respeite os creditos, marcas e licencas de cada fonte. Consulte a [licenca de uso comunitario](LICENSE.md).
