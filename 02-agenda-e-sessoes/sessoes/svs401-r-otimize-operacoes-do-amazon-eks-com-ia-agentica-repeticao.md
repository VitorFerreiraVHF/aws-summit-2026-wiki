## Descricao oficial

Nesta code talk, aprenda a construir sistemas de IA agêntica que automatizam o gerenciamento de clusters Amazon EKS, desde o diagnóstico de problemas até a remediação. Descubra como criar agentes que se conectam com serviços AWS por meio de Model Context Protocol (MCP) para simplificar tarefas operacionais como resposta a incidentes e debugging. A demo de live coding mostrará como sistemas agênticos podem aproveitar o conhecimento tribal de uma empresa para fornecer contexto na resolução de problemas e até auto remediação. Junte-se a nós para descobrir melhores práticas e dicas para aprimorar operações do Amazon EKS com agentes de IA!
