## Descricao oficial

Descubra como projetar soluções de IA agêntica escaláveis e serverless prontas para produção na AWS. Muitas organizações enfrentam dificuldades ao projetar agentes de IA prontos para as complexidades do mundo real. Esta sessão aborda padrões arquiteturais comprovados para sistemas com um ou múltiplos agentes, aplicando princípios de migração monolito para microsserviços e Domain-Driven Design para evitar armadilhas comuns. Você vai explorar implementações práticas usando Amazon Bedrock AgentCore, Amazon API Gateway, AWS Lambda e AWS Fargate com melhores práticas de desenvolvimento. Junte-se a nós para transformar a sua compreensão de IA agêntica de protótipos experimentais para sistemas prontos para produção!
