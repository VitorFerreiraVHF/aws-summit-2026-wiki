## Descricao oficial

Modelos de ML em tempo real são tão bons quanto as features que consomem — features em batch introduzem horas de latência entre a realidade e a inferência. Nesta sessão, aprenda a construir pipelines de feature engineering online que transformam eventos brutos em features prontas para ML em milissegundos. Descubra como usar o Amazon MSK e o Amazon Managed Service for Apache Flink para agregações em streaming, e servir features com baixa latência pelo Amazon SageMaker Feature Store. Abordaremos dados atrasados, correção temporal, consistência e escalabilidade. Saia com uma arquitetura de referência pronta para produção.
