## Descricao oficial

Quebrar silos de dados e unificar informações provenientes de diversas fontes é um desafio complexo. A AWS está transformando o futuro do analytics com integração de dados zero-ETL e federação de queries entre diferentes fontes, serviços, aplicações e ambientes multi-cloud. Participe desta chalk talk para mergulhar em como as abordagens zero-ETL da AWS podem simplificar sua estratégia de integração de dados. Descubra como utilizar o Amazon SageMaker Unified Studio para realizar analytics e machine learning sem mover ou transformar seus dados.
