## Descricao oficial

O ÆIR (Albert Einstein Intelligent Research) é uma plataforma desenvolvida pelo Einstein Hospital Israelita, com a CI&T e AWS, que permite a pesquisadores clínicos fazer perguntas em linguagem natural e obter respostas a partir de bases de dados reais de saúde. O sistema combina um Concierge inteligente com um pipeline de 15 etapas, um processo de integração de dados (Data Onboarding) que abrange mais de 369.000 conceitos médicos e 2,2 milhões de relações biomédicas, além de uma estrutura de avaliação validada por especialistas médicos. A plataforma alcança até 97% de precisão e reduz o tempo de acesso aos dados de dias para minutos, acelerando a geração de evidências clínicas para políticas de saúde pública.
