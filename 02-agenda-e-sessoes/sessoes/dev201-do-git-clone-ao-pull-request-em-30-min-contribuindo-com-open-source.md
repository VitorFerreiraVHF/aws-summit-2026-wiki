## Descricao oficial

Contribuir com open source pode parecer intimidador quando você nunca viu o codebase antes. Nesta sessão ao vivo, vou clonar um projeto real, entender seus padrões de código e convenções sem ler documentação manualmente, e implementar uma feature seguindo as convenções do repositório, tudo com auxílio de um agente de IA. A demonstração termina com um Pull Request legítimo submetido, mostrando como agentes podem acelerar drasticamente sua primeira contribuição em projetos desconhecidos.
