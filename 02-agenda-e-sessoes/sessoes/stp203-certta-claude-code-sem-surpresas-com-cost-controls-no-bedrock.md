## Descricao oficial

Quando 80 engenheiros adotam Claude Code sem governança, os custos explodem. A Certta enfrentou esse desafio ao migrar de API keys para uma arquitetura enterprise na AWS. Nesta sessão, mostramos como implementamos Claude Code com inferência no Amazon Bedrock, login federado, atribuição de custos por usuário, dashboards de monitoramento e enforcement de quotas — sem comprometer a experiência do dev. Você sairá com padrões de arquitetura replicáveis para governar ferramentas de AI Coding em escala enterprise.
