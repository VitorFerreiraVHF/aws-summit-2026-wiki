## Descricao oficial

Engenheiros de dados enfrentam gargalos críticos: construir pipelines do zero e atualizar versões do Apache Spark. Nesta sessão, descubra como agentes de IA da AWS aceleram esses ciclos. Aprenda como o Amazon SageMaker Data Agent transforma linguagem natural em código SQL e Python executável, com total consciência contextual dos seus dados e schemas. Explore também o agente de upgrade do Apache Spark, que reduz projetos de meses para uma semana com análise e transformação automatizada de código. Saia entendendo como automatizar trabalho manual na engenharia de dados, seja construindo ou modernizando aplicações.
