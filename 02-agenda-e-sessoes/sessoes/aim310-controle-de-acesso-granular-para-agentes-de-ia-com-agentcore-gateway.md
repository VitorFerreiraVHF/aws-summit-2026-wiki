## Descricao oficial

Nesta sessão, veja como implementar controle de acesso granular para requisições e respostas de agentes de IA usando interceptors do Amazon Bedrock AgentCore Gateway. Usando interceptors baseados em Lambda que validam identidade do chamador, filtram dinamicamente tools MCP com base em permissões do usuário e inspecionam respostas para redatar dados sensíveis. Cobre interception de REQUEST e RESPONSE, mostrando como enforçar least-privilege, proteger PII e manter isolamento de tenants sem modificar tool servers downstream.
