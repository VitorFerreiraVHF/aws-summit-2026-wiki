## Descricao oficial

Nesta chalk talk, você aprenderá como modernizar arquiteturas Java corporativas usando tecnologias serverless da AWS. Você explorará a transformação de três padrões empresariais comuns: processamento de jobs agendados usando Amazon EventBridge Scheduler com AWS Lambda, tratamento de APIs síncronas com Amazon API Gateway e AWS Lambda, e processamento de tarefas assíncronas via Amazon Simple Queue Service (Amazon SQS) com AWS Lambda. Ao longo da sessão, você aprenderá como estruturar seu projeto Java Serverless, incluindo estratégias para separar lógica de negócio entre funções AWS Lambda e como aproveitar o suporte dos frameworks Spring, Quarkus e Micronaut.
