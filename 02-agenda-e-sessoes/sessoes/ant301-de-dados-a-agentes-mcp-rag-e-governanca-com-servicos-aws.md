## Descricao oficial

Nessa sessão você irá adquirir as habilidades necessárias para criar uma aplicação de IA agêntica usando seus dados mais valiosos. Essa sessão foca na gestão de dados usando processos como Model Context Protocol (MCP) e Retrieval Augmented Generation (RAG), e aborda conceitos que se aplicam a outros métodos de personalização de aplicações de IA agêntica. Descubra melhores práticas arquiteturais usando serviços de bancos de dados da AWS como Amazon Aurora e OpenSearch Service, junto de experiências de dados, analíticas e de streaming no SageMaker Unified Studio. Aprenda conceitos de data lake, governança e qualidade de dados e como o Amazon Bedrock AgentCore e Bedrock Knowledge Bases e outras funcionalidades unem componentes de uma solução.
