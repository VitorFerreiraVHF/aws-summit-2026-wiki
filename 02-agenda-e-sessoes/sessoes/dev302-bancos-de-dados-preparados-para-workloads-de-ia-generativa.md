## Descricao oficial

A corrida pela IA generativa trouxe um novo desafio para times de engenharia: os bancos de dados tradicionais estão realmente preparados para workloads de IA? Nesta sessão, vamos explorar como utilizar bancos de dados relacionais como base para aplicações modernas de IA generativa, aproveitando busca vetorial, embeddings e arquiteturas RAG. Você vai entender as decisões de design, trade-offs de performance e padrões de implementação para construir pipelines de dados robustos para suas aplicações inteligentes.
