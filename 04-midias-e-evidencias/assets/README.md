# Assets

Pasta para arquivos associados a wiki.

Por padrao, midias locais do evento ficam fora do Git publico ate revisao humana, validacao de privacidade, autorizacao de uso e checagem de direitos de terceiros. Mantenha apenas placeholders `.gitkeep` nas pastas abaixo enquanto os arquivos estiverem em curadoria.

## Subpastas sugeridas

| Pasta | Uso |
| --- | --- |
| `fotos` | Imagens revisadas e autorizadas, quando houver |
| `videos` | Videos revisados e autorizados, quando houver |
| `audio` | Audios revisados e autorizados, quando houver |
| `transcricoes` | Transcricoes revisadas e autorizadas, quando houver |
| `contact-sheets` | Folhas de contato revisadas e autorizadas, quando houver |
| `slides` | Slides e materiais permitidos |
| `raw` | Capturas brutas locais, ignoradas por padrao |

Arquivos grandes devem ficar fora do Git comum ou usar uma estrategia propria de armazenamento.
