# Assets

Pasta para arquivos associados a wiki.

## Subpastas sugeridas

| Pasta | Uso |
| --- | --- |
| `fotos` | Imagens selecionadas e prontas para consulta |
| `videos` | Videos curtos ou links documentados em Markdown |
| `audio` | Audios curtos ou amostras |
| `transcricoes` | Transcricoes em Markdown ou texto |
| `slides` | Slides e materiais permitidos |
| `raw` | Capturas brutas locais, ignoradas por padrao |

Arquivos grandes devem ficar fora do Git comum ou usar uma estrategia propria de armazenamento.
