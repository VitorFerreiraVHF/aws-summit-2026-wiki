# Padroes de nomeacao

Use nomes previsiveis para facilitar busca, links e versionamento.

## Arquivos Markdown

Padrao:

```text
nome-curto-em-minusculas.md
```

Exemplos:

- `catalogo-de-sessoes.md`
- `principais-insights.md`
- `generative-ai-machine-learning.md`

## Midias

Padrao recomendado:

```text
YYYY-MM-DD__trilha__sessao-curta__tipo__NN.ext
```

Exemplos:

- `2026-06-10__ai__bedrock-agents__foto__01.jpg`
- `2026-06-10__security__zero-trust__video__01.mp4`
- `2026-06-10__dados__lakehouse__transcricao__01.md`

## Titulos de paginas

Use titulos legiveis, com contexto suficiente para busca.

```md
# Bedrock Agents - Padroes de uso em empresas
```

## Links internos

Prefira links relativos:

```md
[Principais insights](../01-resumo-executivo/principais-insights.md)
```
