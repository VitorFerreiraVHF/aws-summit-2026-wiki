# Fluxo de captura

Use este fluxo sempre que processar fotos, videos, audios, transcricoes ou anotacoes do evento.

## Passo a passo

1. Identifique a sessao no [catalogo de sessoes](../02-agenda-e-sessoes/catalogo-de-sessoes.md).
2. Registre as midias em [indexacao de arquivos](../04-midias-e-evidencias/indexacao-de-arquivos.md).
3. Crie ou atualize a pagina do topico relacionado em [topicos](../03-topicos.md).
4. Extraia aprendizados usando o [template de insight](../templates/insight.md).
5. Conecte cada insight a pelo menos uma evidencia: foto, slide, trecho de video, transcricao ou link oficial.
6. Promova os insights mais fortes para [principais insights](../01-resumo-executivo/principais-insights.md).
7. Registre proximas acoes em [backlog de acoes](../07-acoes-e-follow-up/backlog-de-acoes.md).

## Status sugeridos

| Status | Quando usar |
| --- | --- |
| `bruto` | Conteudo importado, ainda sem tratamento |
| `rascunho` | Conteudo organizado, mas ainda sem revisao |
| `revisado` | Conteudo validado por alguem do time |
| `publicado` | Conteudo pronto para compartilhamento amplo |
| `arquivado` | Conteudo preservado, mas sem uso ativo |

## Criterio para virar insight

Um item deve virar insight quando responder pelo menos uma destas perguntas:

- O que muda na nossa forma de desenhar, operar ou vender solucoes?
- Qual decisao tecnica fica mais clara depois desta sessao?
- Que risco ou oportunidade ficou evidente?
- Que PoC, acelerador, arquitetura ou playbook poderiamos criar?
- Que servico AWS merece investigacao mais profunda?
