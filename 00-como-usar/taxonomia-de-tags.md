# Taxonomia de tags

Tags ajudam a cruzar sessoes, fotos, transcricoes e insights.

## Tags base

| Tipo | Exemplos |
| --- | --- |
| Evento | `aws-summit-2026` |
| Conteudo | `sessao`, `foto`, `video`, `transcricao`, `insight`, `referencia` |
| Maturidade | `bruto`, `rascunho`, `revisado`, `publicado` |
| Impacto | `impacto-alto`, `impacto-medio`, `impacto-baixo` |
| Acao | `poc`, `backlog`, `follow-up`, `decisao-pendente` |

## Tags de topico

| Topico | Tags sugeridas |
| --- | --- |
| Generative AI e Machine Learning | `generative-ai`, `machine-learning`, `bedrock`, `agents`, `rag` |
| Arquitetura e Modernizacao | `arquitetura`, `modernizacao`, `well-architected`, `migration` |
| Dados e Analytics | `dados`, `analytics`, `lakehouse`, `governanca-de-dados` |
| Seguranca, Identidade e Compliance | `seguranca`, `iam`, `compliance`, `zero-trust` |
| Serverless, Containers e Kubernetes | `serverless`, `containers`, `eks`, `lambda` |
| DevOps e Platform Engineering | `devops`, `platform-engineering`, `iac`, `cicd` |
| FinOps e Otimizacao | `finops`, `custos`, `otimizacao`, `governanca` |
| Observabilidade e Operacoes | `observabilidade`, `operacoes`, `resiliencia`, `sre` |
| Casos de uso por industria | `industria`, `case`, `cliente`, `setor` |
